# 🏋️ GymFlow CRM

A full-stack Gym Management CRM built using modern web technologies.

## 🚀 Tech Stack

### Frontend
- Next.js
- React.js
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt.js

## ✨ Features

- Secure Authentication (JWT)
- Role-Based Access Control (Admin, Receptionist, Trainer)
- Member Management
- Dashboard APIs
- Protected Routes
- REST APIs
- Production-level Project Structure

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/abdulkhanmajid01-cmd/GymFlow-CRM.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
